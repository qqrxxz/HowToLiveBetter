# Журнал проверки источников раздела 12 (2026-09-07)

Как проводилась проверка: квота WebSearch в этом сеансе исчерпана, поэтому для поиска нормативных актов использовался поисковый интерфейс базы политических документов правительственного сайта КНР (sousuo.www.gov.cn/search-gov/data, использовался только для поиска URL, в качестве источника не приводится). Каждый URL сначала открывался через WebFetch для подтверждения заголовка, номера документа и текста статей; страницы с полными текстами законов дополнительно скачивались через curl в scratchpad (s12/page_*.html), после удаления тегов оригинал дословно находился по «статья X»; все цитаты ниже взяты из этого локального поиска. На страницах Минтруда и соцобеспечения КНР стоит скрипт против парсинга, WebFetch возвращает пустую страницу, поэтому они открывались через curl с cookie, вычисленным скриптом, и был получен полный текст (заголовок страницы и строка с редакцией сверены). У системы франчайзинга Министерства коммерции сертификат не соответствует домену, WebFetch выдаёт ошибку, поэтому она открывалась через curl -k со сверкой заголовка. DOI через doi.org переадресуется на pubsonline.informs.org, который возвращает 403, поэтому библиографические данные и аннотация сверялись через Crossref API и Semantic Scholar API.
