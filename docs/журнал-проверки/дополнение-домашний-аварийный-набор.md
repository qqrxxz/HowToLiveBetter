# Раздел 1, пункт 26 «Домашний аварийный набор» · Журнал проверки (2026-09-08)

Источник задачи: читатель указал, что для «вещей, которые обязательно должны быть дома, например жгута» нет отдельного места. Проверка показала, что жгут уже есть в разделе 13, пункт 4, не хватает взгляда на само снаряжение в виде списка: огнетушитель, противопожарное покрывало, самоспасатель для эвакуации, содержимое аптечки во всей книге не упоминаются ни разу. По договорённости новый раздел не открывается, в конец раздела 1 добавлен один пункт, подробности вынесены в docs/домашний-аварийный-набор.md.

Об инструментах: WebSearch в этом раунде доступен; API поиска правительственного портала (sousuo.www.gov.cn/search-gov/data) по запросам «домашний запас аварийных материалов» и «пожарная обстановка по стране» в обоих случаях вернул code 1001 без результатов, поэтому официальные URL находили через WebSearch и затем открывали по одному через WebFetch. Сайт Государственного управления пожарно-спасательной службы 119.gov.cn целиком отдаёт 412, как и в прежних записях. Два PDF GB 55036—2022 с правительственных сайтов скачаны, но pdftotext извлекает только цифры и английский текст, у китайских шрифтов нет отображения ToUnicode, pdftoppm на этой машине нет, преобразовать в изображение невозможно, поэтому основной текст положений норматива получить не удалось.

Пояснение к уровню: пункту присвоен B и он отмечен как спорный. Причина в том, что со стороны выгоды есть только этот один Cochrane-обзор, доверительный интервал его основного результата пересекает 1, а размер эффекта в группе «без выдачи снаряжения» сопоставим с общим, что говорит о том, что основной источник снижения травм — не само снаряжение; официальный список — авторитетный документ, но не содержит никакого размера эффекта. Величина выгоды определена подстановкой относительного снижения по мерилу смертности в пороги: IRR 0.89 соответствует примерно 11%, что попадает в интервал 10–20%, отмечено «средняя», а не «большая». Стоимость при комплекте в несколько сотен юаней отмечена как деньги=мало, время=мало, воля=нет.
