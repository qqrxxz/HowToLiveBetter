# Журнал проверки источников раздела 6

Как проводилась проверка: doi.org во всех случаях возвращает переадресацию 302; страницы издательств JAMA/NEJM/Elsevier/Wiley/ACP/RSNA/Nature возвращают WebFetch ошибку 403, страницы PubMed возвращают только уведомление о cookie. Поэтому тексты аннотаций единообразно проверялись через официальный REST-интерфейс Europe PMC (`<https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:<doi>&resultType=core&format=json`>, возвращает те же библиографические данные и abstractText, что и PubMed); в отдельных случаях использовался efetch из NCBI E-utilities. Ниже «фактически открытый URL» — это адрес, по которому WebFetch при проверке успешно вернул содержимое. Все DOI в библиографических данных, возвращённых Europe PMC, однозначно соответствуют названию, авторам и году.
