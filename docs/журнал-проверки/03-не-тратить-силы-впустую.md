# Журнал проверки источников раздела 3

Пояснение: подавляющее большинство страниц издательств (APA psycnet, Elsevier, SAGE, PNAS, Springer, PubMed) на WebFetch с этой машины отвечают 403 / капчей / только уведомлением о cookie, поэтому путь проверки такой: сначала через разрешение <https://doi.org/>... подтвердить, что DOI существует, и посмотреть цель перенаправления (подтвердить издательство и журнал), затем через Europe PMC REST API / Crossref API / OpenAlex API / страницу полного текста PMC / официальный PDF автора или университета получить название, авторов, год и оригинал аннотации. Для каждого пункта перечислены фактически открытые URL и место в оригинале, где находится цитируемое число.
